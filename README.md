# The-Mini-Game
Testing Code for THE [Mini] Game. [Free Use]

Mainly intended for little peaks of how Logic works Mechanically. 
The Primary intent is for *anyone* to be able to see any and all of the formulas and use them as needed. As well as for Narrators to use this as a sort of help with understanding / executing the finer details that come with THE GAME Narration. 

To stay safe, I recommend copy/pasting everything in the Main File into a Python Terminal online, but I'm far too much of a Python Novice to be able to _do_ anything malicious - especially with a Passion Project that's been in development for over a decade.

=== Discrepancies ===  

1 | Fishing.
-  Fishing currently is a build more meant for Single-Player usage & not RP Usage. 
-  This Style of doing things is currently being Tested for compatibility with Discord-Style RP.
-  Durability is *minorly* at play, with it only affecting Fishing ATM. 

2 | XP.
-  XP Requirements and Gained amount are currently lower than they are in the Live Game. 
-  The XP Required is marginally smaller, in the interest of using a similar but much more simplified formula. 
-    The XP Gained is smaller due to being simple placeholder numbers. 

3 | Combat. 
- Combat in this version only supports [Attack, Block, Dodge, Flee] as the Main Actions.
- On top of this, it displays the exact %HP beside it, when fought.
- There is also no [Armor] Value. Bc of this, starting HP is generously set to 100.
