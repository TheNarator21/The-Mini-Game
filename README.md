# The-Mini-Game
Testing Code for THE [Mini] Game. [Free Use]

Mainly intended for little peaks of how Logic works Mechanically. 
The Primary intent is for *anyone* to be able to see any and all of the formulas and use them as needed. As well as for Narrators to use this as a sort of help with understanding / executing the finer details that come with THE GAME Narration. 

To stay safe, I recommend copy/pasting everything in the Main File into a Python Terminal online, but I'm far too much of a Python Novice to be able to _do_ anything malicious - especially with a Passion Project that's been in development for over a decade.
